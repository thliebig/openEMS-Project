Changelog
=========

openEMS is built from several components that are released and versioned
independently of each other, so each one keeps its own changelog:

.. toctree::
   :maxdepth: 2

   openEMS
   CSXCAD

A changelog carries an ``Unreleased`` section while there are user-visible
changes merged since the last release; right after a release there is none. On
https://docs.openems.de/ that section is visible in the *latest* build, which
follows the ``master`` branch; the *stable* build shows only released versions.
