=======
Install
=======

Instructions how to install the **openEMS Project** and its dependencies.

Most users build from source with ``update_openEMS.sh``: install the
dependencies, clone and build, then set up the scripting interface for the
language they work in and verify the result. Ready-made packages exist for
Windows and FreeBSD as a quicker start.
